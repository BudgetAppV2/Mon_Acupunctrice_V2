# Théorie des couleurs — Niche santé/bien-être

## Palettes validées par les données terrain

### Sage Naturel (palette signature Judith) ✅
- Sage green #5C7A5F — confiance, nature, santé
- Sand #F5F0EB — chaleur, douceur
- Beige #E8D5B7 — organique, naturel
- Charcoal #2D3436 — ancrage, professionnalisme
- **Confirmée** par Pantone 2026 (Cloud Dancer + Sage Green)

### Terre & Chaleur
- Terracotta #C4956A — chaleur, authenticité
- Burnt Sienna #8B5A2B — profondeur
- Cream #FDF6EC — lumière
- **Tendance 2026** : Burnt Sienna est couleur complémentaire Pantone

### Tons à privilégier (niche santé holistique)
- Verts sauge / olive / forêt — nature, guérison
- Beiges / crèmes / off-white — chaleur, douceur
- Terracotta / terre cuite — authenticité, ancrage
- Charcoal / gris foncé — professionnalisme (pas noir pur)
- Blanc chaud (Cloud Dancer) — minimalisme, espace

### Tons à éviter
- Bleu vif / électrique — trop tech/corporate
- Violet / rose vif — trop commercial/beauté
- Néon / fluorescent — trop agressif
- Noir pur #000000 — trop dur (utiliser charcoal)
- Gradients multicolores — le "AI look" par excellence

## Psychologie des couleurs en santé

| Couleur | Émotion | Usage |
|---------|---------|-------|
| Vert sauge | Confiance, guérison, nature | Accent principal, CTA |
| Beige/crème | Chaleur, accueil, douceur | Fond, pill background |
| Terracotta | Authenticité, terre, ancrage | Accent secondaire |
| Blanc chaud | Clarté, espace, minimalisme | Texte sur fond sombre |
| Charcoal | Expertise, sérieux | Texte sur fond clair |

## Contraste WCAG

Ratio minimum 4.5:1 pour le texte normal.
Formule de luminance relative :
```
L = 0.2126 * R + 0.7152 * G + 0.0722 * B
Ratio = (L1 + 0.05) / (L2 + 0.05)
```

### Combinaisons validées
- Blanc #FFFFFF sur Sage #5C7A5F → ratio 4.7:1 ✅
- Blanc #FFFFFF sur Charcoal #2D3436 → ratio 12.1:1 ✅
- Charcoal #2D3436 sur Cream #FDF6EC → ratio 10.8:1 ✅
- Blanc #FFFFFF sur Terracotta #C4956A → ratio 3.2:1 ⚠️ (stroke nécessaire)

### Règle pour le texte sur vidéo
Le fond vidéo est imprévisible → toujours ajouter stroke + shadow.
Le contraste WCAG s'applique au texte + son stroke, pas au texte seul.
