# Règles de design — Validées par les données terrain

Sources : VISUAL_ANALYSIS_RESEARCH.md + VISUAL_TRENDS_2026_RESEARCH.md

## Les 10 règles

1. **Stroke 2px noir minimum sur tout texte** — non négociable pour la lisibilité sur vidéo
2. **Bold condensée majuscules pour les hooks** — Bebas Neue ou Anton, 60-72px
3. **48-56px minimum pour les sous-titres** — sur canvas 1080×1920
4. **Tons terreux dominent la niche wellness** — sage, terracotta, beige, charcoal
5. **Sous-titres dans 80% des Reels performants** — doublent le watch time
6. **Hook dans les 2 premières secondes** — gros texte, question ou affirmation bold
7. **Safe zone droite 120px** — boutons IG like/comment/share
8. **1 animation max par élément** — simplicité > complexité
9. **Filtre warm subtil pour 3/4 des contenus santé** — pas de cool/blue
10. **CTA avec background pill** — tendance montante, haute conversion

## Pattern #1 des Reels viraux talking head

```
[0-2s]  Hook GROS texte centré (Bebas Neue 64px, majuscules, stroke 3px)
[2-end] Visage qui parle + sous-titres bold outline (Inter 52px, stroke 2px)
[Fin]   CTA avec background pill sage (Poppins 56px)
```

## Tendance 2026 : "Imperfect by Design"

L'ère du polish parfait est terminée. Les créateurs qui performent montrent
de l'authenticité brute. Ne PAS surproduire — garder le côté naturel et chaleureux.
Le contenu face caméra authentique > le contenu sur-édité.

## Tendance 2026 : Serif Revival

Les polices serif (DM Serif Display, Playfair Display) signalent expertise
et crédibilité — parfait pour une professionnelle de santé.
