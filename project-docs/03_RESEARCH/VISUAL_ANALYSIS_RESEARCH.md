### 1B — Style visuel des Reels sante/bien-etre performants

**Observations concretes :**

**Couleurs dominantes :** Muted retro pastels — sage green, warm mustard, soft peach, terracotta. Les tons terreux dominent massivement. Les couleurs vives (rouge, bleu electrique) sont quasi absentes de la niche.

**Filtres :** Generalement chauds avec une legere desaturation. Pas de filtre froid. Le look "Instagram 2025" en wellness = warm, slightly faded, natural light.

**Sous-titres :** Present dans ~80% des Reels performants. Style dominant : bold outline blanc avec stroke noir 2px. Le style "karaoke" (mot actif en couleur) est populaire mais pas majoritaire — le bold outline simple reste le #1.

**Hooks :** Le hook texte (premieres 2 secondes) est TOUJOURS en bold condensee, centree, avec un fond semi-transparent ou un stroke epais. Taille : ~1/5 de la hauteur de l'ecran.

**Mise en page talking head :**
```
[0-2s]  Hook texte plein ecran (bold, centre)
[2-end] Visage qui parle + sous-titres en bas (y=80-85%)
```

## Theme 2 — Presets et templates CapCut

### 2A — Presets populaires 2025-2026

**Categories de presets CapCut :**
1. **Kinetic titles** — texte anime dynamique, trending
2. **Beat-synced transitions** — coupes synchronisees avec la musique
3. **Subtitle styles** — 10+ styles pre-faits
4. **LUT-style filters** — color grading en 1 tap
5. **Emoji overlays** — stickers animes sur les sous-titres
6. **AI auto-captions** — sous-titres automatiques avec brand fonts

**Pour le talking head educatif :**
- Le preset dominant est "clean subtitles" + filtre warm + hook texte bold
- Les intros animees sont courtes (< 1s) ou absentes
- L'accent est sur les SOUS-TITRES, pas sur les effets
- Le filtre est subtil (warm tone, legere desaturation)

### 2B — Templates talking head

**Pattern #1 — "Hook & Talk" (le plus viral) :**
```
Frame 1 (0-2s) : Texte hook GROS, centre, fond flou ou noir semi-transparent
Frame 2+ : Visage + sous-titres style bold outline en bas
Fin : CTA texte ou sticker "Follow"
```

**Pattern #2 — "3 Points" (educatif) :**
```
Intro : "3 choses que tu ne sais pas sur [sujet]"
Point 1 : Texte "1." + sous-titres
Point 2 : Texte "2." + sous-titres
Point 3 : Texte "3." + sous-titres
Fin : CTA "Enregistre pour plus tard"
```

**Pattern #3 — "POV / Coulisses" (connecter) :**
```
Pas de hook texte — commence direct sur l'action
Sous-titres discrets (minimal style, petit texte)
Filtre warm vintage
Fin : Question dans le texte
```

## Theme 3 — Palettes de couleurs validees par la data

### 3A — Couleurs qui performent

**Donnees concretes :**
- Sage green + beige + charcoal = la palette #1 de la niche wellness
- Terracotta + cream + olive = forte en confiance et ancrage
- Teal + gold + cream = sophistiquee mais moins courante
- **Les tons terreux performent MIEUX que les pastels vifs** en wellness
- **Fond sombre (charcoal) + texte clair** = meilleur contraste sur video
- **Fond clair (cream) + texte sombre** = plus difficile sur video (le fond change)

### 3B — Corrections a apporter aux palettes existantes

**Palette "Sage Naturel" (actuelle Judith) : VALIDEE** — c'est exactement dans la tendance. Sage green + beige + charcoal est la combinaison la plus utilisee en wellness.

**Palette "Ocean Calm" : A AJUSTER** — le teal est moins courant en MTC/acupuncture. Remplacer par un vert plus terreux.

**Palette "Minimal Pro" : A GARDER** — parfait pour le contenu educatif/serieux.

**Ajout recommande : palette "Dark Clinic"**
```
Primary : #2D3436 (charcoal)
Background : #1A1A2E (dark blue-black)
Accent : #87A878 (sage)
Text : #FFFFFF (white)
Highlight : #E8D5B7 (warm beige)
```
→ Pour le contenu du soir ou les demos avec eclairage tamise

## Theme 4 — Typographie concrete

### 4A — Fonts REELLEMENT utilisees

**Hooks (3 premieres secondes) :**
- **Bold condensee** domine massivement : Bebas Neue, Anton, Oswald, Fjalla One
- Taille : 60-72px sur 1080px de large (~5-7% de la largeur)
- TOUJOURS en majuscules pour les hooks
- Stroke noir 2-4px + shadow obligatoire

**Sous-titres :**
- **Sans-serif clean** : Inter, Roboto, Open Sans, Montserrat
- Taille : 48-56px sur 1080px de large
- Bold ou semi-bold (pas de regular — trop fin sur video)
- Stroke 2px noir minimum

**CTA :**
- Meme font que les sous-titres, parfois avec fond pill colore
- Taille legèrement plus grande (52-60px)

### 4B — Effets texte les plus courants

**Classement par popularite (observe sur les Reels viraux) :**

1. **Bold outline** (stroke noir 2-3px + fill blanc) — #1 inconteste
2. **Shadow portee** (shadow noire douce) — #2, souvent combine avec le stroke
3. **Background pill** (fond arrondi semi-transparent) — #3, monte en popularite
4. **Karaoke highlight** (mot actif en couleur) — #4, trending mais pas encore majoritaire
5. **Neon glow** — #5, niche fitness/tech, PAS pour wellness

**Effets "amateurs" a EVITER :**
- Texte blanc sans aucun effet (illisible sur scenes claires)
- Rainbow/gradient text (incoherent avec le ton pro)
- Texte trop petit (< 45px sur 1080px)
- Police decorative pour les sous-titres (illisible)
- Animation agressive (shake, glitch) pour du contenu sante

## Theme 5 — Regles de design concretes

### 5A — Safe zones exactes 2026

**Mesures confirmees pour Instagram Reels (1080x1920) :**

```
┌─────── 1080px ────────┐
│    108px TOP MARGIN    │  ← nom utilisateur, heure
│                        │
│ 60px                   │
│  ←   SAFE ZONE  → 120px│  ← boutons like/comment/share
│     996 × 1400px       │
│                        │
│                        │
│    320px BOTTOM MARGIN │  ← caption, audio, scrubber
└────────────────────────┘

Zone prime pour le hook : y=300 a y=600 (centre haut)
Zone sous-titres : y=1400 a y=1550 (juste au-dessus de la caption)
Zone CTA : y=1300 a y=1450
```

**Elements UI Instagram qui couvrent le contenu :**
- **Droite :** coeurs, commentaires, share, save, audio (120px de large)
- **Bas :** caption, nom, audio bar (320px de haut)
- **Haut :** nom utilisateur, options (108px de haut)

### 5B — Lisibilite texte sur video

**Tailles confirmees :**
- **Hook titre :** 60-72px (1080p) — occupation ~1/5 de l'ecran vertical
- **Sous-titres :** 48-56px (1080p) — 1 ligne = 1/20 a 1/30 de la hauteur
- **CTA :** 52-60px
- **Minimum absolu :** 45px (en dessous, illisible sur mobile)

**Stroke et shadow :**
- **Stroke minimum :** 2px noir (pour tout texte sur video)
- **Stroke recommande :** 3-4px pour les hooks
- **Shadow :** `shadowBlur: 4px`, `shadowOffsetX: 2px`, `shadowOffsetY: 2px`, `shadowColor: rgba(0,0,0,0.8)`
- **Background pill :** `rgba(0,0,0,0.5)` ou `rgba(0,0,0,0.6)` avec `borderRadius: fontSize/3`

**Regle d'or :** Toujours combiner AU MOINS stroke + shadow. Sur une video avec des scenes variables, c'est la seule garantie de lisibilite.

### Regles de design validees par la data

1. **Stroke 2px noir minimum** sur tout texte video (non negociable)
2. **Bold condensee en majuscules** pour les hooks (Bebas Neue, Anton)
3. **48-56px minimum** pour les sous-titres
4. **Tons terreux** dominent la niche wellness (sage, terracotta, beige)
5. **Sous-titres presents dans 80%** des Reels performants
6. **Hook dans les 2 premieres secondes** (gros texte, question ou affirmation bold)

8. **1 animation max par element** — le contenu est le hero, pas les effets
9. **Filtre warm subtil** pour 3/4 des contenus (sauf educatif = clean)
10. **CTA avec background pill** est la tendance montante
