# Recherche — Agent de design graphique pour presets vidéo pro

## Mission
Explorer comment construire un agent IA spécialisé en design graphique pour la création
de presets vidéo professionnels pour les réseaux sociaux. L'objectif est d'avoir un
système capable de créer des presets de qualité graphiste professionnelle, pas des
combinaisons aléatoires génériques.

L'approche est en 3 temps :
1. Création de l'agent spécialisé (skills, system prompt, capacités)
2. Construction de la knowledge base graphisme (données, règles, tendances)
3. Génération de presets validés (itération, auto-critique, preview visuel)

Utilise Exa extensivement pour chaque thème.
