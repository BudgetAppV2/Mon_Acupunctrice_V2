## 1. Changement majeur 2025-2026 : Mots-clés > Hashtags

### Le shift fondamental
Les trois plateformes (Instagram, Facebook, YouTube) fonctionnent maintenant comme
des **moteurs de recherche**. Le virage est confirmé par Adam Mosseri (Head of Instagram)
et les mises à jour algorithmiques de 2025-2026.

**AVANT (2020-2023) :** 30 hashtags = découvrabilité
**MAINTENANT (2025-2026) :** Mots-clés dans les captions = découvrabilité

### Ce que ça change pour Judith
- Les captions doivent contenir des **mots-clés recherchés** par les utilisateurs
- Les hashtags sont limités à **3-5 maximum** (Meta a réduit leur impact)
- Les mots-clés doivent apparaître dans la **première phrase** de la caption
- L'algorithme "lit" la caption pour comprendre le sujet et le catégoriser

## 2. Instagram Reels — SEO 2026

### Signaux de ranking (par ordre d'importance)
1. **Watch time / rétention** — la vidéo est-elle regardée jusqu'au bout?
2. **Saves** — le signal le plus puissant (= "je veux revoir ça")
3. **Shares** — partages en DM ou en Story
4. **Mots-clés dans la caption** — première phrase cruciale
5. **Mots-clés dans le texte à l'écran** — l'IA lit le texte superposé
6. **Alt text de l'image de couverture** — champ souvent ignoré
7. **Hashtags** (3-5 max, pertinents au niche)

### Checklist caption Instagram pour Judith
```
[Première phrase avec mot-clé principal]

[2-3 phrases de valeur éducative]

[Call-to-action : question ou invitation à sauvegarder]

[3-5 mots-clés naturels dans le texte]

#lasourceensoi #acupuncture #[1-3 hashtags spécifiques au sujet]

🔗 judithtremblay.com
```

### Mots-clés stratégiques pour Judith (français + anglais)
**Fertilité :** acupuncture fertilité, fertilité naturelle, FIV acupuncture,
concevoir naturellement, aide à la conception
**Grossesse :** acupuncture grossesse, nausées grossesse, bébé en siège,
accouchement naturel, préparation accouchement
**Post-partum :** post-partum acupuncture, baby blues, récupération accouchement,
fatigue post-natale, allaitement
**Bien-être :** acupuncture stress, acupuncture anxiété, acupuncture douleur,
médecine traditionnelle chinoise, MTC, santé naturelle
**Enfants :** acupuncture enfant, acupuncture bébé, coliques nourrisson,
acupuncture pédiatrique

### Le texte à l'écran compte!
Instagram utilise l'OCR (reconnaissance de texte) pour lire le texte
superposé dans les vidéos. Quand Judith ajoute du texte dans l'éditeur,
utiliser des **mots-clés** dans le texte à l'écran aide le référencement.
Ex: "3 points d'acupuncture pour le stress" comme texte superposé.

## 3. YouTube Shorts — SEO 2026

### Différences clés avec Instagram
- YouTube est le **2e moteur de recherche mondial** après Google
- Les Shorts apparaissent dans **Google Search** (pas juste YouTube)
- L'algorithme teste chaque Short sur une "seed audience" dans la **première heure**
- La **satisfaction utilisateur** (survey post-watch) compte plus que le watch time brut
- Les Shorts contribuent à l'autorité du **channel** entier

### Signaux de ranking YouTube Shorts
1. **Rétention** — % regardé (looped = très bon signal)
2. **Pas de swipe** — l'utilisateur ne swipe pas = bon signal
3. **Titre** — mots-clés dans les 40 premiers caractères
4. **Description** — mots-clés dans les 2 premières lignes (visibles avant "...voir plus")
5. **Mots parlés** — YouTube transcrit automatiquement et indexe les mots prononcés
6. **Tags/Hashtags** — #Shorts est utile pour le classement initial

### Format description YouTube optimal pour Judith
```
[Titre descriptif avec mot-clé : ex "Acupuncture fertilité : 3 points à connaître"]

[2-3 phrases de description avec mots-clés naturels]

📍 La Source en Soi — Clinique d'acupuncture, Montréal
🔗 Prendre rendez-vous : https://judithtremblay.com

#Shorts #Acupuncture #[mot-clé spécifique] #lasourceensoi
```

### YouTube + Google Search
Les Shorts sont maintenant indexés dans Google Search. Ça veut dire que
quand quelqu'un cherche "acupuncture fertilité Montréal" sur Google,
un Short de Judith peut apparaître dans les résultats. C'est ÉNORME
pour le SEO local.

## 4. Facebook Reels — SEO 2026

### Changements majeurs 2025-2026
- **Toutes les vidéos sont maintenant des Reels** (plus de distinction vidéo/Reel)
- **50% du fil** vient de comptes non-suivis (découvrabilité organique)
- Les **saves et shares** sont les signaux les plus puissants
- Le "dwell time" (temps passé à lire la caption) est un signal
- **Contenu natif > liens externes** (ne pas mettre de liens dans les captions FB)

### Signaux de ranking Facebook
1. **Shares** — le signal #1 (partagé = validé)
2. **Comments** — surtout les commentaires longs et les conversations
3. **Saves** — "je veux revoir"
4. **Dwell time** — temps passé sur le post
5. **Contenu natif** — vidéo uploadée directement > lien YouTube

### Format description Facebook pour Judith
```
[Accroche avec question ou statement fort]

[2-3 lignes de valeur]

[Call-to-action : "Enregistre ce post si tu veux essayer!"]

#lasourceensoi #acupuncture #[sujet]
```

### Stratégie
La clinique "La Source en Soi" a ~10 000 followers Instagram.
En utilisant #lasourceensoi, les publications de Judith apparaissent
dans le fil du hashtag de la clinique → exposition à leur audience.

### Utilisation

- **Pas nécessaire** sur YouTube (la clinique n'y est probablement pas)

  sont plus importants que les hashtags)

## 6. Stratégie multi-plateforme pour Judith

### Même vidéo, captions adaptées
La vidéo est identique sur les 3 plateformes (MP4 9:16).
Mais la **caption/description** doit être adaptée :

| Élément | Instagram | YouTube | Facebook |
|---------|-----------|---------|----------|
| Longueur caption | 150-300 mots | 100-200 mots | 100-200 mots |
| Mots-clés | Dans la 1ère phrase | Dans le titre + 2 premières lignes | Dans l'accroche |
| Hashtags | 3-5 | #Shorts + 2-3 | 3-5 |
| #lasourceensoi | Oui | Optionnel | Oui |
| Lien Wix | En fin (non cliquable) | Dans description (cliquable!) | Non (FB pénalise les liens) |
| CTA | "Sauvegarde ce Reel" | "Abonne-toi" | "Partage à quelqu'un" |

### Fréquence recommandée
- **3 Reels/semaine** — mardi, jeudi, samedi
- Publier entre **11h-13h** ou **18h-20h** (heures Montréal)
- YouTube : le même jour ou le lendemain (pas de double-dip)

### Ce qui compte vraiment pour Judith
1. **Les 3 premières secondes** — accroche visuelle forte (texte à l'écran)
2. **Éduquer > vendre** — contenu de valeur, pas de pitch
3. **Consistance** — 3x/semaine pendant 3 mois minimum
4. **Les saves sont l'or** — créer du contenu "à revoir" (listes, tips, routines)

Encourager Judith à ajouter du texte à l'écran contenant des mots-clés
(l'OCR d'Instagram et YouTube lit ce texte).

### YouTube description
Inclure automatiquement :
- Titre descriptif avec mot-clé
- Lien Wix cliquable

- #Shorts + hashtags pertinents

Ajouter un champ configurable où Judith peut saisir ses hashtags récurrents
(#lasourceensoi, #acupuncturemontreal, etc.). Ces hashtags sont automatiquement
ajoutés aux captions générées.
