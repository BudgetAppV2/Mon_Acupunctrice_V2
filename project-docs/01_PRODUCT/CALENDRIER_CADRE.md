# Calendrier-cadre de contenu — Mon Acupunctrice Hub
# Plan de 6 mois (Avril → Septembre 2026)

## Les 3 piliers de Judith
1. **FERTILITÉ** — préconception, PMA, cycle menstruel, ovulation
2. **GROSSESSE** — prénatal, postnatal, accouchement, allaitement
3. **BIEN-ÊTRE** — menstruations, ménopause, stress, anxiété, sommeil

## Les 4 types de posts
- **ÉDUQUER** → Judith enseigne quelque chose (savais-tu que...)
- **CONNECTER** → Judith montre qui elle est (son quotidien, son humanité)
- **AIDER** → Judith donne un truc concret à essayer
- **PROUVER** → Résultat, témoignage, parcours d'une patiente

## Le pipeline Blogue → Réseaux
```
ARTICLE DE BLOGUE (1x par mois)
  │
  ├──→ REEL #1 — ÉDUQUER (résumé de l'article en 30-60 sec)
  │      └──→ STORY — lien vers l'article complet
  │
  ├──→ REEL #2 — AIDER (un truc tiré de l'article)
  │
  └──→ STORY — rappel de l'article 1 semaine plus tard
```

## Les Stories — Guide rapide

Les stories sont plus spontanées que les Reels. Pas besoin de les planifier
autant, mais voici les types qui fonctionnent :

| Type de Story | Fréquence | Exemple |
|---------------|-----------|---------|
| Coulisses | 1-2x/semaine | Judith qui prépare sa salle, ses aiguilles |
| Sondage/Question | 1x/semaine | "Tu savais que l'acupuncture aide pour X?" |
| Partage de blogue | Quand article sort | "Nouvel article! Lien ici" |
| Rappel RDV | 1x/semaine max | "Des places se sont libérées cette semaine" |
| Repost | Quand pertinent | Partager un article ou un post d'un autre compte |

## Règles simples pour Judith

1. **Régularité > Perfection.** Un post OK chaque semaine vaut mieux que
   un post parfait une fois par mois.

2. **Parle comme tu parles.** Le contenu qui fonctionne le mieux c'est
   quand on sent la vraie Judith, pas un discours marketing.

3. **Chaque post = UN message.** Pas trois idées dans un Reel.
   Un seul point clair.

4. **Le blogue nourrit les Reels.** Un article = 2-3 Reels faciles.
   Tu as déjà fait le travail de réflexion, il reste juste à le filmer.

5. **Les témoignages sont de l'or.** Demande à tes patientes si tu peux
   utiliser leur histoire (anonymisée). C'est ce qui convainc les gens.

6. **1 post sur 5 peut mentionner la prise de RDV.** Les autres construisent
   la confiance. Ne vends pas, aide.
