## Comment tout se connecte — Les pipelines

### Pipeline 1 : Blogue → Réseaux sociaux
```
Judith écrit un article de blogue (1x/mois)
  │
  │ Le Hub détecte le nouvel article (ou Judith colle le lien)
  │
  ├──→ Mission 1 : Reel ÉDUQUER
  │    "Résume l'article en 30-60 sec devant la caméra"
  │    → Publié sur Instagram + Facebook + YouTube
  │
  ├──→ Mission 2 : Story automatique
  │    Image générée avec le titre de l'article
  │    Texte : "Nouvel article! Lien dans ma bio 👆"
  │    → Publiée automatiquement via l'API Stories
  │
  ├──→ Mission 3 : Reel AIDER
  │    "Un truc concret tiré de l'article"
  │    → Publié 3-4 jours après le premier Reel
  │
  └──→ Mission 4 : Story rappel (J+7)
       "Tu as manqué mon article sur X?"
       → Publiée automatiquement
```

### Pipeline 2 : Idée spontanée → Publication
```
Judith a une idée (ou utilise la transcription vocale R2)
  │
  ├──→ L'idée est sauvegardée dans la Banque
  │    Catégorisée : pilier (fertilité/grossesse/bien-être)
  │                  type (éduquer/connecter/aider/prouver)
  │
  ├──→ Le Hub la place dans le calendrier selon les missions de la semaine
  │
  ├──→ Judith crée le Reel dans l'éditeur
  │
  └──→ Publication multi-plateforme (Instagram + Facebook + YouTube)
       + Story de promotion automatique
```

### Pipeline 3 : Témoignage → Preuve sociale
```
Judith reçoit un bon feedback d'une patiente
  │
  ├──→ Elle le note dans la Banque d'idées (type: PROUVER)
  │
  ├──→ Mission : Créer un Reel texte narratif
  │    (le format qu'elle voulait faire avec les boucles d'oreilles!)
  │    Texte anonymisé qui défile sur une vidéo d'ambiance
  │
  └──→ La fin du Reel : "Prête à essayer? Lien dans ma bio"
```

Quand Judith publie du contenu lié à la clinique (ex: Stories des

- #acupuncturemontreal #acupuncturerosemont (SEO local)
