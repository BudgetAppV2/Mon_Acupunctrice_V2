## Résumé exécutif

Le site de Judith a une niche hyper-ciblée (fertilité + grossesse + pédiatrie) dans un quartier précis (Rosemont/Beaubien) — c'est exactement ce que Google privilégie pour le SEO local. Les fondations techniques sont solides (HTTPS, canonicals, sitemap, meta descriptions, alt text). Cependant, le site ne se positionne pas encore dans les résultats de recherche pour ses mots-clés cibles. Les 3 priorités qui auront le plus d'impact sont : (1) séparer les services en pages dédiées, (2) ajouter du schema markup LocalBusiness, et (3) continuer à publier du contenu blog ciblé sur les keywords identifiés.

## Schema JSON-LD — Comment ça marche et quoi mettre

### C'est quoi le JSON-LD?

C'est un bloc de code invisible ajouté dans le `<head>` de la page. Les visiteurs
ne le voient jamais — c'est uniquement pour Google. Ça dit à Google de façon
structurée : "Ce site appartient à une acupunctrice qui s'appelle Judith, elle
pratique à cette adresse, avec ce numéro, ces services." Sans ça, Google doit
deviner ces infos à partir du texte. Avec le schema, Google peut afficher des
résultats enrichis : adresse, téléphone, horaires, étoiles directement dans
les résultats de recherche.

### Judith vs La Source en Soi — qui met quoi?

Judith est une **praticienne individuelle** qui exerce **à** La Source en Soi.
La clinique a déjà son propre Google Business Profile (4.9/5, 1215 avis).
Le schema sur acupuncturejudith.ca ne doit PAS dupliquer la fiche de la clinique.

On utilise le type `Person` avec `worksFor` qui pointe vers la clinique.
Ainsi Google comprend que Judith est une personne, acupunctrice, qui travaille
à La Source en Soi. Les deux entités sont liées sans se dupliquer.

### Comment l'ajouter dans Wix

1. Wix > Paramètres du site > SEO avancés (ou "Custom Code")
2. Ajouter un code dans le `<head>` de la page d'accueil
3. Coller le JSON-LD ci-dessus dans une balise `<script type="application/ld+json">`
4. Le code sera invisible pour les visiteurs mais lu par Google
5. Valider avec https://validator.schema.org/ après publication
