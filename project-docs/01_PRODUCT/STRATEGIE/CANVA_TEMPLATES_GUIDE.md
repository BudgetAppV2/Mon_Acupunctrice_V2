# Templates Canva pour Judith — Guide de création

## Le concept

Judith crée UN design en format Story (1080x1920) dans Canva.
Le Hub utilise cette image pour :
1. Les Stories Instagram → image complète telle quelle
2. Le blog Wix → auto-crop du centre en 16:9 (1200x675)

Pour que ça marche, le texte important doit être dans la ZONE SAFE
(le tiers central de l'image, entre 30% et 70% de la hauteur).

## Comment créer les templates dans Canva

### Étape 1 — Créer un projet (dossier) dans Canva

1. Va sur canva.com → Projets (sidebar gauche)
2. Crée un nouveau dossier : "Templates Blog Acupuncture"
3. Ce dossier va contenir tous les templates de base

### Étape 2 — Créer le premier template

1. Clique "Créer un design" → "Taille personnalisée"
2. Entre : 1080 x 1920 px (format Story Instagram)
3. Nomme-le : "Template Blog — Vert sage"

### Étape 3 — Designer le template avec les zones

Structure du template (de haut en bas) :

```
┌──────────────────────────────────┐
│                                  │   ← ZONE HAUTE (0-30%)
│     Logo / "La Source en Soi"    │     Branding, logo, décoratif
│     Judith Dufour-Savard         │     Visible en Story seulement
│                                  │
├ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┤
│                                  │   ← ZONE SAFE (30-70%)
│                                  │     ★ Le titre du blog va ICI ★
│     [Titre de l'article]         │     Visible dans TOUS les formats
│                                  │     (Story + blog crop 16:9)
│     [Sous-titre optionnel]       │
│                                  │
├ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┤
│                                  │   ← ZONE BASSE (70-100%)
│     CTA "Prends rendez-vous"    │     Visible en Story seulement
│     gorendezvous.com/...         │     Coupé en mode blog
│                                  │
└──────────────────────────────────┘
```

### Éléments de design à inclure

**Fond :**
- Photo stock ou photo de Judith/clinique
- Overlay semi-transparent pour lisibilité du texte
- Couleur de marque : vert sage #5C7A5F ou variantes

**Zone haute (0-30% = 0px à 576px) :**
- Texte "LA SOURCE EN SOI" en blanc, petite taille
- Sous-texte "Judith Dufour-Savard · Acupunctrice"
- Optionnel : petit logo/icône

**Zone safe / centre (30-70% = 576px à 1344px) :**
- Placeholder texte : "[TITRE DE L'ARTICLE]" en gros et gras
- Police : Avenir, Montserrat, ou Inter
- Couleur : blanc sur fond sombre
- C'est ce que Judith va modifier pour chaque blog
- Laisser assez d'espace pour 2-3 lignes de titre

**Zone basse (70-100% = 1344px à 1920px) :**
- "Prends rendez-vous"
- "gorendezvous.com/lasourceensoi"
- "Lien dans ma bio" (petit, discret)

### Étape 4 — Créer des variantes

Dupliquer le template et créer 3-4 variantes :

1. **Vert sage** — fond vert #5C7A5F, ambiance zen
2. **Automne** — tons orangés/dorés, feuilles
3. **Printemps** — tons verts clairs, nature
4. **Neutre** — fond beige/crème, minimaliste

### Étape 5 — Partager comme template

Pour chaque design :
1. Clique "Partager" (en haut à droite)
2. Clique "Plus" en bas du menu
3. Choisis "Lien de template"
4. Copie le lien

Quand Judith clique le lien, Canva crée une COPIE
du design dans son compte. Elle modifie la copie
sans toucher à l'original.

### Étape 6 — Intégrer les liens dans le Hub

Les liens de template Canva peuvent remplacer le bouton
"Créer dans Canva" actuel dans le BlogEditor.
Au lieu d'ouvrir canva.com/create/instagram-stories
(page vierge), le bouton ouvrirait un template pré-fait.

## Fonts recommandées (disponibles dans Canva)

- Avenir (utilisé sur le site Wix)
- Montserrat (alternative Google Fonts)
- Playfair Display (pour les titres élégants)
- Lato (pour le body text)

## Workflow final de Judith

1. Elle écrit un article dans le Hub (éditeur WYSIWYG)
2. Elle clique "Créer l'image" → le template Canva s'ouvre
3. Elle change le titre et la photo de fond dans Canva
4. Elle télécharge le JPG
5. Elle l'importe dans le Hub (bouton "Importer")
6. Le Hub utilise l'image pour la Story (complète) et le blog (crop centre)
7. Elle clique "Publier sur Wix"
8. La Story promo se publie automatiquement avec le tag @lasourceensoi

avant d'exporter. Ça l'aide à placer son texte correctement.
