## Milestones Phase 2

NOTE : Ces milestones touchent le site Wix. Certains peuvent être faits
via l'API Wix ou le dashboard. D'autres nécessitent l'éditeur Wix 
(validation Judith requise).

### W1 — Fix urgent Schema LocalBusiness
- Corriger "Judith Dufourd Savard" → "Judith Dufour Savard"
- Ajouter @type HealthAndBeautyBusiness
- Ajouter priceRange, openingHours, geo coordinates
- Se fait dans le dashboard Wix (SEO Settings)

### W2 — Fix lien Instagram
- Le site pointe vers instagram.com/judith.acupuncture
- Le vrai compte est instagram.com/mon_acupunctrice
- Se fait dans l'éditeur Wix (header icons)

### W3 — Section blog sur page d'accueil
- Ajouter le widget "Posts récents" natif Wix avant le footer
- 3 cartes en ligne avec thumbnail + titre
- CTA "Voir tous les articles →"
- Se fait dans l'éditeur Wix

### W4 — Optimiser le blog title et la structure
- Blog title : "Blogue d'acupuncture | Conseils santé naturelle | Montréal"
- Chaque article devrait avoir un schema BlogPosting
- Se fait dans dashboard Wix (Blog Settings + SEO per page)

### W5 — Optimiser les meta tags des pages clés
- Services : inclure les mots-clés fertilité, grossesse, pédiatrie
- Bienfaits : mots-clés douleur, stress, bien-être
- Acupuncture sociale : mot-clé unique différenciateur
- Se fait dans dashboard Wix (SEO per page)

### W6 — Créer des sous-pages services (optionnel mais fort SEO)
- /services/fertilite — page dédiée fertilité + acupuncture
- /services/grossesse — page dédiée grossesse
- /services/pediatrie — page dédiée enfants/bébés
- Chaque page cible un mot-clé spécifique
- Se fait dans l'éditeur Wix (nouvelles pages)
